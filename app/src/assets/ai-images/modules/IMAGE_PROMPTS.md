# AI Image Generation Prompts for Coming Soon Modules

Use these prompts with Gemini Imagen, Midjourney, DALL-E, or similar AI image generators.

## Style Reference
All images should match this consistent style:
- **Background**: Pure black or very dark (#0A0A0B)
- **Primary Color**: Golden/amber glow (#F59E0B, warm golden yellow)
- **Secondary Color**: Purple/lavender flowing ribbons or smoke (#8B5CF6, #7C3AED)
- **Style**: Minimalist line art with glowing elements, symbolic/iconic representation
- **Composition**: Central glowing motif with purple smoke/ribbon accents
- **Mood**: Mystical, premium, knowledge-oriented
- **Format**: Square (1:1 aspect ratio), 400x400px minimum

## Base Style Prompt
Add this to all prompts:
```
Dark black background, minimalist golden line art illustration with warm amber glow emanating from center, purple flowing smoke ribbons as accent, mystical premium aesthetic, no text, centered composition, vector art style with soft glow effects
```

1. Generate images at 512x512 or higher resolution
2. Export/convert to WebP format for web optimization
3. Resize to approximately 400x400px
4. Target file size: 20-40KB per image
5. Save to: `app/src/assets/ai-images/modules/`
6. Naming convention: `module-{module-id}.webp`
